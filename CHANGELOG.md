# Changelog

User-visible changes are recorded here. Entries under **Unreleased** describe the current
worktree and do not claim that a package has been published.

## Unreleased

### Added

- Standalone Angular grid and tile template directive with a serializable layout contract.
- Cell-based positioning, pointer movement and resizing, collision refusal, per-tile size
  limits, live/edit modes, and tile locks.
- Keyboard movement, resizing, nearest-fit jumps, announcements, and focus management.
- Deterministic layout normalization and programmatic tile addition and removal.
- Projected Angular content with preserved widget state during movement.
- Independent design token package, gallery, and reduced-motion styling.
- Library unit tests, desktop Chromium acceptance tests, and packed consumer verification.
- Five-minute demo, integration documentation, and open-source community guidance.

### Licensing

- Added the MIT license text and contributor guidance.
