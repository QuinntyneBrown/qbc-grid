# Project governance

qbc-grid is an independent, maintainer-led open-source project. Quinntyne Brown is the
current maintainer and makes final decisions on scope, API changes, merging, and releases.

## Decisions

Use a GitHub issue to propose a change. Describe the problem, expected behavior, and its
fit with the [product scope](docs/specs/L1.md). Contributors can discuss alternatives in
the issue or pull request. The maintainer records the decision there and resolves disagreements.

Changes should keep the library small, independent of host applications, accessible from
the keyboard, and backed by behavior tests. A passing test suite alone does not guarantee
acceptance of a new feature.

## Maintenance and releases

The maintainer reviews contributions, triages issues, coordinates private security
reports, and prepares releases. The repository has no fixed release schedule, support SLA,
or long-term-support policy. See [SECURITY.md](SECURITY.md) for security maintenance.

Additional maintainers may be invited based on sustained contributions and responsible
review. Changes to ownership or governance should be documented in this file.

All participation is subject to the [code of conduct](CODE_OF_CONDUCT.md).
