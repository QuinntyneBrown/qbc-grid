# Contributors

qbc-grid is maintained by [Quinntyne Brown](https://github.com/QuinntyneBrown).

The [Git history](https://github.com/QuinntyneBrown/qbc-grid/commits/main/) and
[GitHub contributor graph](https://github.com/QuinntyneBrown/qbc-grid/graphs/contributors)
record code and documentation contributions. Issue reports, design feedback,
accessibility reviews, and helping other users also contribute to the project.

To get involved, read [CONTRIBUTING.md](CONTRIBUTING.md). Maintainer responsibilities
and decision-making are described in [GOVERNANCE.md](GOVERNANCE.md).
