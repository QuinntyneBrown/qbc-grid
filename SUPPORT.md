# Getting help

Start with the [README](README.md), [API guide](docs/api.md), and
[five-minute walkthrough](docs/demo.md).

For usage questions, search [existing issues](https://github.com/QuinntyneBrown/qbc-grid/issues).
If no issue answers your question, open one with a clear description and the smallest
example that demonstrates the problem. Include:

- qbc-grid revision or package version and Angular version;
- browser, operating system, and viewport size;
- grid inputs, a sample layout, and the interaction that causes the problem;
- expected and actual behavior, plus relevant errors or screenshots.

Remove secrets and private data from reproductions. For proposed features, explain the
use case and check the [scope](docs/specs/L1.md) first.

Support is provided by maintainers and contributors as time permits, without a guaranteed
response time. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
